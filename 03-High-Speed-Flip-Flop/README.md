# High-Speed TSPC D Flip-Flop

## Overview
This project focuses on the transistor-level design and optimization of a high-speed True Single-Phase Clock (TSPC) D Flip-Flop using CMOS technology.

The objective is to improve switching performance while analyzing the trade-offs between propagation delay, power consumption, and transistor sizing.

## Design Specifications
- **Architecture:** TSPC D Flip-Flop
- **Technology:** 0.25 μm CMOS
- **Supply Voltage:** 2.5 V
- **Simulation Tool:** LTspice

## Design & Optimization
- Transistor sizing optimization (W/L)
- Clock-to-Q propagation delay analysis
- Setup time evaluation
- Average power consumption
- Power-Delay Product (PDP)
- Parametric sweep simulations

## Technologies & Tools
- CMOS Digital IC Design
- VLSI
- Transistor-Level Simulation
- LTspice / SPICE

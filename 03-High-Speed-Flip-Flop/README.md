# High-Speed TSPC Flip-Flop

## Overview
Transistor-level design and optimization
of a high-speed TSPC D Flip-Flop
using 0.25 um CMOS technology.

## Design Specifications
- Technology: 0.25 um CMOS
- Supply Voltage: 2.5 V
- Architecture: TSPC D Flip-Flop

## Analysis
- Clock-to-Q Delay
- Setup Time
- Transistor Sizing Optimization
- Power Consumption
- Power-Delay Product (PDP)

- LTspice
- SPICE

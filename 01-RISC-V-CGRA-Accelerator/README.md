# RISC-V Controlled CGRA Accelerator

## Overview
Diploma thesis focused on the design and
integration of a RISC-V-controlled
Coarse-Grained Reconfigurable Array (CGRA).

## Technologies
- Chisel / Scala
- RISC-V
- CGRA Architecture
- RTL Design
- FPGA

## Main Components
- Custom Control Unit
- MMIO Interface
- CGRA Integration
- Functional Verification

## Status
Ongoing development.

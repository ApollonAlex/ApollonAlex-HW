## Featured Projects

### 1. [RISC-V Controlled CGRA Accelerator — Diploma Thesis](01-RISC-V-CGRA-Accelerator/)

**Status: Ongoing**

Development of a RISC-V-controlled Coarse-Grained Reconfigurable Array (CGRA) accelerator, focusing on custom control logic, memory-mapped I/O (MMIO), processor–accelerator integration, and functional verification.

**Technologies:** Chisel, Scala, RISC-V, Verilog, CGRA, FPGA Design

### 2. [Piccolo Lightweight Block Cipher](02-Piccolo-Cipher/)

RTL implementation of the Piccolo lightweight block cipher in VHDL, supporting 80-bit and 128-bit encryption keys, with dedicated key scheduling, encryption/decryption datapaths, and functional simulation.

**Technologies:** VHDL, RTL Design, ModelSim, Vivado

### 3. [High-Speed TSPC Flip-Flop](03-High-Speed-Flip-Flop/)

Transistor-level design and optimization of an 11-transistor True Single-Phase Clock (TSPC) D Flip-Flop using 0.25 μm CMOS technology.

Through critical-path analysis and selective transistor sizing, the optimized design achieved:

- **24.5% reduction** in worst-case clock-to-Q delay.
- **9.6% improvement** in Power-Delay Product (PDP).
- **88.48 ps** worst-case clock-to-Q delay at nominal operating conditions.

**Technologies:** CMOS, LTspice, SPICE, VLSI, Timing & Power Analysis

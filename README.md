## Featured Projects

### 1. RISC-V Controlled CGRA Accelerator — Diploma Thesis (Ongoing)
Development of a RISC-V-controlled Coarse-Grained Reconfigurable Array (CGRA) system, focusing on hardware control, memory-mapped interfaces, and accelerator integration.

**Technologies:** Chisel, Scala, RISC-V, CGRA, FPGA

### 2. Piccolo Lightweight Block Cipher
VHDL-based implementation of the Piccolo lightweight block cipher, supporting 80-bit and 128-bit keys.

**Technologies:** VHDL, RTL Design, Functional Simulation

### 3. High-Speed TSPC Flip-Flop
Transistor-level design and optimization of a high-speed True Single-Phase Clock (TSPC) D flip-flop using 0.25 µm CMOS technology, with timing, power, and power-delay product analysis.

**Technologies:** CMOS, LTspice, SPICE, VLSI
